What You Will Learn

From Binary Numbers to 64-bit ARM

CSEN 20 introduces the fundamental concepts behind how computers represent, process, and manipulate information. You will learn how software interacts with computer hardware at a low level and write programs using ARM assembly language.

  • Inspect registers and memory
